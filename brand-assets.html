웹 화면에서 (모듈)

brand-logos.js를 불러온 뒤, 로고가 필요한 곳에 넣습니다. 색은 CSS color로 제어돼요(로고가 currentColor라 배경에 맞춰 흑/백 자동).

// <script src="brand-logos.js"></script> 로드 후 el.innerHTML = TWBrand.dotGames(); // tactileWorld / tactileImageBank / dotGames / superDot /* CSS */ .logo { height:28px; color:#fff; } // 어두운 배경이면 흰색

디자인 작업에서 (파일)

Figma·문서 등에는 아래 SVG 파일을 그대로 넣으세요. 밝은 배경엔 black, 어두운 배경엔 white 버전. 벡터라 어떤 크기로도 선명해요.

4종 모두 라이브 index.html에서 추출한 실제 벡터 로고이고, 전부 단색이라 color 한 줄로 흑/백을 전환합니다. 새 브랜드가 생기면 TWBrand.register('name', '<svg…>')로 등록해 전 화면에서 바로 쓸 수 있어요.
