플랫폼 로고를 필요한 곳에서 꺼내 쓰는 단일 자산 모듈입니다. 웹은 brand-logos.js, 디자인은 .svg 파일을 사용하세요.

어두운 배경#FFFFFF SVG
사용법

웹 화면에서 (모듈)

페이지에 brand-logos.js를 불러온 뒤, 로고가 필요한 곳에 넣습니다. 색은 CSS color로 제어돼요(로고가 currentColor라 배경에 맞춰 흑/백 자동).

// <script src="brand-logos.js"></script> 로드 후 el.innerHTML = TWBrand.tactileWorld(); // SVG 삽입 /* CSS */ .logo { height:28px; color:#fff; } // 어두운 배경이면 흰색

디자인 작업에서 (파일)

Figma·문서 등에는 위 SVG 파일을 그대로 넣으세요. 밝은 배경엔 black, 어두운 배경엔 white 버전을 씁니다. 벡터라 어떤 크기로도 선명해요.
